# JHoster v3.74.0

## Logs Tabs UI

- Ana sol sidebar yapisi korunmustur.
- Logs sayfasi icinde tab menu kullanimi eklenmistir.
- Her uygulama icin ayri log tab hazirlanmistir:
  - Desktop
  - Agent
  - Apache
  - Nginx
  - MySQL
  - PHP
  - Mailpit
  - System
- Clear ve Open File aksiyonlari secili log tabina gore calisir.
- Servis durum loglari ilgili uygulama tabina yazilir.
- Logs CSS stilleri acik tema ile uyumlu hale getirilmistir.
