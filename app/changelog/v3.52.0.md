# v3.52.0

## Eklenenler

- JHoster Desktop ana dashboard sade bilgi mimarisine cekildi.
- Search bar, global status badge, notification ve profile alani eklendi.
- Agent, Stack Profile, Workspace Root ve Overall Health ozet kartlari eklendi.
- Overview, Runtime Versions, Quick App, Workflow ve Diagnostics tab satiri eklendi.
- Services alani tablo duzenine alindi.
- Quick Actions, Activity Log ve System Overview alt grid duzeni eklendi.

## Guncellenenler

- `LauncherView.java` v3.52.0 clean dashboard render akisina guncellendi.
- `jhoster-modern.css` v3.52.0 sade dashboard stilleriyle genisletildi.
- `pom.xml` desktop version degeri 3.52.0 yapildi.
- `jhoster-desktop.properties` app version degeri 3.52.0 yapildi.

## Korunanlar

- Controller is kurali tasimaz; sadece handler baglar.
- Service lifecycle aksiyonlari Service katmaninda kalir.
- Portable tool acma davranisi Tool katmaninda kalir.
- Veritabani butonu HeidiSQL Portable acmaya devam eder.
