# v3.38.0 - Process Inspection Probe

## Eklenenler

- `WindowsProcessProbeTool` eklendi.
- `GET /api/v1/process/{component_code}/inspect` endpointi eklendi.
- `GET /api/v1/process/{component_code}/status?prefer_real=true` destegi eklendi.
- Guarded adapter status ve preflight cevaplarina `real_process_probe` eklendi.
- Desktop Service Manager status aksiyonu inspect endpointine baglandi.

## Guvenlik

- Real start/stop default kapali kalir.
- Shell komutu kullanilmaz.
- Windows disi ortamda probe bloklanir.
