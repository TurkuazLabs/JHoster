# Version: 3.50.0
# Aciklama: Sade root layout ve folder layout endpoint revizyonunu kaydeder

Bagimli Oldugu Katman: Service | Tool | Config | View

## Eklenenler

- Sade root layout standardi: `app`, `bin`, `data`, `etc`, `logs`, `tmp`, `www`, `backup`, `cache`.
- Agent kaynaklari `app\agent` altina alindi.
- Desktop kaynaklari `app\desktop` altina alindi.
- State dosyalari `data\jhoster` altina alindi.
- Quick App proje kok dizini `www` olarak guncellendi.
- Folder layout endpointleri eklendi.
- Desktop quick action `Projects` butonu `www` klasorune baglandi.

## Endpointler

- `GET /api/v1/folder-layout`
- `GET /api/v1/folder-layout/plan`
- `POST /api/v1/folder-layout/apply?dry_run=true`
- `POST /api/v1/folder-layout/apply?dry_run=false`

## Guvenlik

- Layout apply veri silmez.
- Sadece eksik standart klasorleri olusturur.
- Legacy klasorler icin rapor verir.
- Path root disina cikamaz.
