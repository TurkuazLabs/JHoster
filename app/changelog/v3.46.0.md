# v3.46.0

## Eklenenler

- Desktop sistem tepsisi menusu eklendi.
- Laragon benzeri alt sag menu akisi kuruldu.
- JHoster Goster, Gizle, Panel, www, Hizli uygulama, Araclar, servisler, runtime menu, Profil, Secenekler ve Cikis aksiyonlari eklendi.
- Pencere kapatma islemi uygulamayi sonlandirmak yerine tray'e gizleyecek sekilde ayarlandi.
- Cikis menu aksiyonu tray ikonunu kaldirip uygulamayi temiz kapatir.
- Veritabani tray aksiyonu HeidiSQL Portable acma akisini kullanir.

## Guvenlik

- Gercek process execution varsayilan olarak kapali kalir.
- Start/Stop/Restart aksiyonlari Service Manager guard akisindan gecer.
- Shell komutu tray tarafinda dogrudan calistirilmaz.
