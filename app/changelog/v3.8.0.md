# v3.8.0 Service Adapter Layer

## Eklenenler

- Runtime service adapter katalogu
- Simulated, PHP, Nginx, MySQL ve Node.js adapterleri
- Service adapter API endpointleri
- Process manager icinde adapter sonucu
- Manifest `installer.runtime_adapter` destegi
- JavaFX launcher `Adapters` butonu
- Service adapter test scripti

## Guvenlik

Gercek runtime start/stop bu surumde kapali kaldi. Simulated adapter sadece JSON state kaydi yapar. PHP, Nginx, MySQL ve Node.js adapterleri dry-run hazirlik seviyesindedir.
