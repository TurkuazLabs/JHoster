# v3.67.0 Hosts Auto Inspect ve Repair

Bu surumde JHoster managed hosts bloku sadece yazilan bir cikti olmaktan cikarildi. Agent artik mevcut hosts hedefini okuyabilir, proje registry ile karsilastirabilir ve eksik/stale kayitlari repair akisiyle onarabilir.

## Endpointler

- `GET /api/v1/hosts-auto/inspect`
- `GET /api/v1/hosts-auto/repair-plan`
- `POST /api/v1/hosts-auto/repair`

## Koruma

- JHoster sadece `# BEGIN JHOSTER AUTO HOSTS` ve `# END JHOSTER AUTO HOSTS` arasini yonetir.
- Docker Desktop, Laragon ve manuel satirlar managed blok disinda korunur.
- Gercek Windows hosts yazimi icin Windows ve admin yetkisi gerekir.
