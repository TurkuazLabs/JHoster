# v3.37.0 - Process Real Preflight Guard

## Eklenenler

- Process manager icin `preflight` endpointi eklendi.
- Process manager icin `restart` endpointi eklendi.
- `start`, `stop`, `restart` endpointlerine `allow_real_execution` guard parametresi eklendi.
- Apache, Nginx, MySQL ve PHP icin guarded local process adapter eklendi.
- Real execution varsayilan olarak kapali tutuldu.
- Desktop Service Manager satirlarina `Preflight` butonu eklendi.
- Desktop Service Manager restart akisi agent `restart` endpointine baglandi.

## Guvenlik

- Shell komutu kullanilmaz.
- Komutlar argv listesi olarak calistirilir.
- Real execution sadece `allow_real_execution=true` ile denenir.
- App real process config `enabled=false` ise gercek process calismaz.
- Executable bulunamazsa gercek process calismaz.

## Yeni Endpointler

- `GET /api/v1/process/{component_code}/preflight`
- `POST /api/v1/process/{component_code}/restart?dry_run=true`
- `POST /api/v1/process/{component_code}/restart?dry_run=false&allow_real_execution=false`
- `POST /api/v1/process/{component_code}/start?dry_run=false&allow_real_execution=true`
- `POST /api/v1/process/{component_code}/stop?dry_run=false&allow_real_execution=true`
