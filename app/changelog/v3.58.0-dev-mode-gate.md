# JHoster v3.58.0 - Dev Mode Gate

- Raw agent API endpoint butonlari normal UI'dan kaldirildi.
- Developer Tools menusu sadece Dev Mode aktifken gorunur.
- Dev Mode su yollarla acilir:
  - JHoster acilirken Shift basili tutulur.
  - `--dev` argumani kullanilir.
  - `-Djhoster.dev=true` system property verilir.
  - `JHOSTER_DEV_MODE=1` environment flag verilir.
- `http://127.0.0.1:8751/api/v1/web-server-profiles` gibi endpoint butonlari Developer Tools altina tasindi.
- Normal modda Virtual Hosts, Projects, Apps ve Workflow sayfalari endpoint butonlari yerine guvenli bilgi kartlari gosterir.
