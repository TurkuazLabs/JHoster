# v3.31.0 - Web Server Workflow Rollback Guard

## Eklenenler

- Unified workflow icin rollback guard eklendi.
- `rollback_on_failure=true` parametresi eklendi.
- Publish sonrasi validate veya reload hatasinda otomatik rollback calisir.
- Son workflow publish kaydina gore manuel rollback endpointi eklendi.
- `WebServerWorkflowRollbackTool` eklendi.
- Rollback test scripti ve komut kisayolu eklendi.

## Endpoint

```text
POST /api/v1/web-server-workflow/{project_code}/rollback?dry_run=true
POST /api/v1/web-server-workflow/{project_code}/rollback?dry_run=false
```
