# v3.53.1 - Web Server Port Guard

## Duzeltildi

- Apache ve Nginx ayni anda 80/443 public portlarini sahiplenemez.
- Start All butonu Nginx'i otomatik baslatmaz; varsayilan frontend olarak Apache baslatilir.
- Tekil Apache/Nginx Start ve Restart aksiyonlari agent port guard kuralindan gecirilir.

## Kural

- Apache ve Nginx birlikte calisacaksa portlari cakismayacak.
- 80/443 public portlarini ayni anda sadece bir frontend web server kullanacak.
- Mevcut varsayilan profilde Apache ve Nginx ikisi de 80/443 kullandigi icin biri calisirken digeri bloklanir.
