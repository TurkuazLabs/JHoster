# v3.34.0 - Desktop Workflow Bridge

## Eklenenler

- JavaFX Desktop icin unified web server workflow bridge eklendi.
- Active profile sorgulama butonu eklendi.
- Workflow plan butonu eklendi.
- Guvenli dry-run workflow butonu eklendi.
- Workflow runs ve locks listeleme butonlari eklendi.
- Desktop API route config sinifi eklendi.
- Desktop HTTP request tool sinifi eklendi.
- Desktop workflow request/result modelleri eklendi.

## Guvenlik

- Desktop workflow dry-run aksiyonu `dry_run=true` ve `allow_real_execution=false` ile calisir.
- Gercek reload islemi Desktop uzerinden bu surumde acilmadi.

## Test

- Python compile basarili.
- FastAPI import basarili.
- Route sayisi 113.
- Desktop workflow bridge non-JavaFX siniflari `javac` ile derlendi.
- Desktop Maven compile yardimci scripti eklendi.
- Maven test ortamda `mvn` bulunmadigi icin calistirilmadi.
