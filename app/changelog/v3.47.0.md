# v3.47.0

## Eklenenler

- Laragon benzeri portable `bin` klasor standardi eklendi.
- `bin` altinda 20 bilesen klasoru standart hale getirildi.
- Desktop tray `Araclar` altina portable tool girisleri eklendi.
- HeidiSQL, Cmder, Git Bash, Notepad++, Ngrok icin quick action aday pathleri eklendi.
- Composer ve Yarn icin klasor acma aksiyonlari eklendi.
- Redis, Memcached ve Sendmail registry placeholder kayitlari eklendi.
- Ana servis install pathleri `bin/*` standardina hizalandi.

## Guvenlik

- Real execution varsayilan olarak kapali kalmaya devam eder.
- Tray tool acma islemleri sadece bilinen portable path adaylarini kullanir.
- Servis calistirma yine process guard uzerinden yapilir.
