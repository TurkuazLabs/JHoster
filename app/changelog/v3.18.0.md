# v3.18.0

## Eklenenler

- Nginx executable controller eklendi.
- Nginx executable service eklendi.
- Nginx executable registry repository eklendi.
- Nginx executable detector tool eklendi.
- `JHOSTER_NGINX_EXE` env path adayi eklendi.
- Snapshot test adayi `snapshot/nginx/bin/nginx.exe` olarak tanimlandi.
- `/api/v1/nginx-executable` endpointleri eklendi.
- `agent/test-nginx-executable.ps1` test dosyasi eklendi.
- JavaFX launcher icin Nginx Exe butonu eklendi.

## Guvenlik

- Gercek `nginx -v` ve `nginx -t` calistirilmaz.
- Shell execution kapali kalir.
- Real nginx execution kapali kalir.
- Bu surum sadece path discovery ve registry kaydi yapar.
