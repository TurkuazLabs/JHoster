# v3.34.1 - Desktop CSS Warning Patch

## Duzeltmeler

- JavaFX CSS parser tarafinda uyari veren `-fx-font-weight: 650;` degeri `700` olarak duzeltildi.
- `run-desktop-javafx.ps1` icinde `JAVA_HOME` Maven calismadan once ayarlanacak sekilde duzeltildi.

## Eklenenler

- `desktop/test-css-syntax-guard.ps1` eklendi.
- `desktop/commands/test-desktop-css-command.ps1` eklendi.

## Not

NetBeans exec classpath calistirma akisi `Unsupported JavaFX configuration: classes were loaded from unnamed module` uyarisi gosterebilir. Bu uyari uygulamayi durdurmaz. Temiz module-path calistirma icin `desktop/commands/run-desktop-javafx.ps1` kullanilabilir.
