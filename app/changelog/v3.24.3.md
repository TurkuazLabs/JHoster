# JHoster v3.24.3

## Desktop Modern UI Patch

- JavaFX launcher arayuzu modern kart tabanli tasarima gecirildi.
- Sidebar, hero alan, status kartlari ve aksiyon kartlari eklendi.
- JavaFX CSS tema dosyasi eklendi.
- Launcher pencere boyutu 1180x760 olarak guncellendi.
- Minimum pencere boyutu 1040x680 olarak ayarlandi.
- Agent endpointleri ve backend akislar degistirilmedi.
