# v3.61.0 - Launcher Bootstrap + GitHub Release Check

## Eklenenler

- `MainApp` artik `LauncherBootstrapApplication` ile baslar.
- Splash ekran eklendi.
- Local version `jhoster-desktop.properties` icinden okunur.
- GitHub latest release endpoint kontrolu eklendi.
- Repo tanimli degilse update check sessiz atlanir.
- Internet yoksa veya GitHub gec cevap verirse desktop acilisi bloklanmaz.
- Update varsa release sayfasini acma secenegi sunulur.
- Gercek dosya degistiren updater sonraki surume birakildi.
