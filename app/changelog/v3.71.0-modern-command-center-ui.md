# JHoster v3.72.0

- Modern Command Center hero alani eklendi.
- Ust akis artik header, command hero, quick actions, new site wizard ve panel bolumleri olarak okunur.
- Environment Snapshot kartlari eklendi.
- Recommended Preset ve Portable Runtime Layer bilgi kartlari eklendi.
- New Site Wizard stack secimi daha modern kart/pill gorunumune alindi.
- Light tema korunarak glass-style kartlar, daha yumusak shadow, yuvarlatilmis alanlar ve premium rozetler eklendi.
- Tab menu kaldirma karari korundu; LauncherView icinde `TabPane` veya `new Tab` kullanilmadi.
- Backend agent akislarina dokunulmadi; bu surum UI/UX modernizasyonudur.
