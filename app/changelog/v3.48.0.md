# v3.48.0

## Eklenenler

- Portable bin version scanner eklendi.
- Runtime Manager icin `Scan Bin` aksiyonu eklendi.
- PHP, Node ve Python icin folder-based activation eklendi.
- Agent endpointleri eklendi:
  - `GET /api/v1/runtime-versions/portable-scan`
  - `GET /api/v1/runtime-versions/{family}/portable-scan`
  - `POST /api/v1/runtime-versions/{family}/activate-portable`
- `dry_run=false` portable activation sonrasi ana process profile `install_path` sync edilir.
- Laragon benzeri ornek version klasorleri eklendi.

## Guvenlik

- Path traversal guard var.
- Shell komutu calistirilmaz.
- Real process start/stop hala ayri guard ile korunur.
