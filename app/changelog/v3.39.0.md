# v3.40.0 - Service Manager Real Process Profile

## Eklenenler

- `GET /api/v1/process/{component_code}/real-profile`
- `GET /api/v1/process/{component_code}/real-profile/plan`
- `POST /api/v1/process/{component_code}/real-profile/apply`
- Real process install path planlama ve kaydetme akisi
- `real_process.enabled` bilgisini dry-run guard ile yonetme
- Path guard: servis yolu JHoster root disina cikamaz
- Test scripti: `agent/test-process-real-profile.ps1`
- Dokuman: `docs/SERVICE_MANAGER_REAL_PROFILE.md`

## Guvenlik

- Apply endpointi varsayilan `dry_run=true` gelir.
- Real start/stop icin hala `allow_real_execution=true` gerekir.
- Shell komutu kullanilmaz.
- Executable path kontrolu preflight asamasinda yapilir.
