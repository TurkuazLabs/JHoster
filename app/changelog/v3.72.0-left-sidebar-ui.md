# JHoster v3.72.0

## Degisenler

- Normal mod artik sol sidebar menu ile acilir.
- Tab menu ve kalabalik Command Center hero akisi normal gorunumden kaldirildi.
- New Site artik sol menude ana giris noktasi olarak gorunur.
- Sag icerik alani sadece secilen menunun sayfasini gosterir.
- New Site sayfasi stack secimli wizard olarak korunur.
- Services, Projects, Virtual Hosts, Apps, Runtime Versions, Workflow, Tools, Logs ve Settings sol menuden erisilir.
- Light tema korunarak sidebar, topbar ve page header polish yapildi.

## Korunanlar

- Quick App stack parametreleri korunur.
- Apache / Nginx, MySQL, PHP, Mailpit secimleri korunur.
- Hosts Auto, License, Package Center ve servis aksiyonlari korunur.
- Dev Mode kapisi korunur.
