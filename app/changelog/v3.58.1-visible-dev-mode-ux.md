# JHoster v3.58.1 - Visible Dev Mode UX Patch

## Degisiklikler

- Dev Mode normal UI icinden daha net ayrildi.
- Shift ile acilinca sol menude ayri `DEVELOPER` grubu gorunur.
- `Developer Tools` menusu turuncu/kirmizi uyarili stil ile ayrildi.
- Ust barda `DEV MODE ACTIVE` rozeti daha belirgin hale getirildi.
- Developer Tools sayfasina uyarili bilgilendirme bandi eklendi.
- Settings penceresinde Dev Mode acikken `Developer` sekmesi gorunur.
- Normal acilista Developer Tools, Diagnostics ve Developer settings sekmesi gizli kalir.

## Not

Bu surum UI patch seviyesidir. Servis veya agent endpoint davranisini degistirmez.
