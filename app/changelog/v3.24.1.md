# JHoster v3.24.1

## Patch

- Desktop Maven proje surumu `3.2.1` olarak guncellendi.
- `MainApp` JavaFX `Application` sinifindan ayrildi.
- `FxApplication` sinifi eklendi.
- NetBeans `exec:exec` akisi icin JavaFX launcher guard sorunu giderildi.
- `pom.xml` Java 21 compiler release ve OpenJFX runtime dependency ayarlari netlestirildi.
- Desktop calistirma yardimci scripti eklendi.

## Test Notu

Bu paket Linux ortaminda XML ve dosya yapisi kontrolunden gecirildi.
Maven calistirma testi Windows/NetBeans ortaminda kullanici tarafinda yapilmalidir.
