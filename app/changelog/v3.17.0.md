# v3.17.0 - Hosts Apply Safety Layer

## Eklenenler

- Hosts apply controller eklendi.
- Hosts apply service eklendi.
- Hosts apply registry repository eklendi.
- Admin privilege tool eklendi.
- Hosts file apply tool eklendi.
- Snapshot apply modu eklendi.
- Gercek Windows hosts apply icin admin kontrolu eklendi.
- Backup tabanli rollback endpointleri eklendi.
- PowerShell test scripti eklendi.
- JavaFX launcher'a Hosts Apply butonu eklendi.

## Guvenlik

- Varsayilan olarak `real_write=false` kullanilir.
- Gercek Windows hosts dosyasina yazmak icin `real_write=true` gerekir.
- Windows olmayan sistemlerde gercek hosts apply reddedilir.
- Admin olmayan Windows oturumunda gercek hosts apply reddedilir.
- Rollback sadece kayitli backup dosyasindan yapilir.
