# v3.43.0

## Eklenenler

- JHoster klasor standardi dokumani eklendi.
- JHoster Desktop ana ekran wireframe dokumani eklendi.
- Desktop Quick Actions paneli eklendi.
- Web, Veritabani, Terminal, Root, Projects ve Logs butonlari eklendi.
- Veritabani butonu HeidiSQL Portable acacak sekilde baglandi.
- HeidiSQL Portable icin `bin\heidisql` yer tutucu klasoru eklendi.

## Guvenlik

- HeidiSQL acma islemi shell kullanmadan ProcessBuilder ile yapilir.
- Klasor acma islemleri Desktop API uzerinden yapilir.
- Terminal acma islemi JHoster root icinde baslar.
