# v3.51.0

## Eklenenler

- Compact dashboard servis satirlarina Start, Stop ve Restart butonlari eklendi.
- Quick Actions bolumu alt dock yapisina cekildi.
- Portable Tools dock eklendi.
- Bin, Cmder, Git Bash, Notepad++, Ngrok, Composer ve Yarn butonlari Desktop UI'a baglandi.
- Agent ust kontrol alanina Open Panel butonu eklendi.
- Desktop CSS tarafina compact service action stilleri eklendi.
- Desktop Laragon UI compile test scripti eklendi.

## Guncellenenler

- `LauncherView.java` v3.51.0 olarak guncellendi.
- `LauncherController.java` portable tool action handlerlarini baglayacak sekilde guncellendi.
- `jhoster-modern.css` v3.51.0 light UI duzenine guncellendi.
- `pom.xml` desktop version degeri 3.51.0 yapildi.

## Korunanlar

- Veritabani butonu HeidiSQL Portable acmaya devam eder.
- Controller katmaninda is kurali tutulmaz.
- Quick action is kurallari Service katmaninda kalir.
- Executable acma isi Tool katmaninda kalir.
