# v3.36.0 - Desktop Service Manager UI

## Eklenenler

- JavaFX Desktop ana ekrana Service Manager paneli eklendi.
- Apache, Nginx, MySQL ve PHP icin status, start, stop ve restart butonlari eklendi.
- Desktop service manager icin `ServiceManagerSummary` modeli eklendi.
- `ServiceResultFormatterService` ile process API cevaplari okunabilir summary haline getirildi.
- `ServiceManagerDesktopService` ile Desktop -> Agent process endpointleri baglandi.
- Agent `app_registry.json` icine varsayilan servis kayitlari eklendi.
- `process_state.json` ile servis durumlari stopped baslangic haliyle tanimlandi.
- `apache`, `nginx`, `mysql`, `php` runtime klasorleri hazirlandi.

## Guvenlik

- Gercek Windows process calistirma bu surumde acik degildir.
- Service Manager v1, safe simulated state uzerinden Laragon benzeri start/stop/status deneyimini baslatir.
- Real process adapter baglantisi sonraki surume birakildi.

## Test

- Python compile basarili.
- FastAPI import basarili.
- Route sayisi 113 olarak korundu.
- Process API ile Apache status/start/stop smoke test basarili.
- Desktop service manager non-JavaFX siniflari `javac` ile derlendi.
- Desktop JavaFX kaynak agaci stub compile ile syntax kontrolunden gecti.
