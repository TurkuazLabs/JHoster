# JHoster v3.24.4

## Eklendi

- Desktop hero alanina `Stop Agent` butonu eklendi.
- Desktop hero alanina `Restart Agent` butonu eklendi.
- Sidebar Control grubuna `Stop Agent` ve `Restart Agent` etiketleri eklendi.
- `AgentProcessService` icine `stopAgent`, `restartAgent` ve `isManagedAgentRunning` metodlari eklendi.

## Duzeltildi

- Start butonu vardi ancak agent lifecycle buton seti eksikti.
- Stop islemi sadece desktop tarafindan baslatilan managed process icin guvenli calisacak sekilde sinirlandi.

## Not

- Bu surum Nginx veya Apache backend adapter akisini degistirmez.
- Harici olarak baslatilmis agent process stop edilmez; sadece desktop launcher tarafindan baslatilan process yonetilir.
