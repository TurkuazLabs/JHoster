# v3.66.0 Hosts Auto Sync

- `GET /api/v1/hosts-auto` sync gecmisi listeler.
- `GET /api/v1/hosts-auto/latest` son sync kaydini dondurur.
- `GET /api/v1/hosts-auto/plan` managed hosts blok planini gosterir.
- `POST /api/v1/hosts-auto/sync` snapshot veya gercek Windows hosts dosyasini senkronlar.
- Quick App ve Project create islemleri hosts auto sonucunu response icine ekler.
- Gercek Windows hosts yazimi sadece Windows + admin yetkisiyle calisir.
- Site wizard icin Quick App karti New Test Site metinleriyle guncellendi.
