# JHoster v3.10.0 - Runtime Version Manager

## Eklenenler

- Runtime version manager service katmani eklendi.
- Runtime version state repository eklendi.
- `/api/v1/runtime-versions` endpointi eklendi.
- `/api/v1/runtime-versions/{family}` endpointi eklendi.
- `/api/v1/runtime-versions/{component_code}/activate` endpointi eklendi.
- Manifest normalize akisina `runtime_family` alani eklendi.
- JavaFX launcher icin `Runtime Versions` butonu eklendi.
- `agent/test-runtime-versions.ps1` test dosyasi eklendi.

## Guvenlik

- Runtime aktivasyonu sadece app registry icinde kurulu olan kayitlar icin yapilir.
- Dry-run varsayilan olarak aciktir.
- Bu surum gercek servis PATH degistirme veya system service yazma islemi yapmaz.
