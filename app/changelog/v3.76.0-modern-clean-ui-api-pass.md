# JHoster v3.76.0

## Degisiklikler

- Sol sidebar menu gruplari sade hale getirildi: Create, Operate, Resources, Observe, Settings.
- Calismayan topbar search, shortcut, fake alert ve profil pill elemanlari kaldirildi.
- Topbar canli durum kartlarina cevrildi: Plan, Sites, Hosts, Engine.
- Projects, Virtual Hosts ve Apps sayfalari sadece bilgi karti olmaktan cikarildi; calisan aksiyon kartlari eklendi.
- Quick App scaffold metinlerinden yanlis anlasilabilecek placeholder ifadeleri temizlendi.
- Action executor download mesaji Package Download service yonlendirmesiyle daha net hale getirildi.
- API audit ve release cleanliness denetimi tekrarlandi.
