# v3.30.0 - Web Server Unified Workflow

## Eklenenler

- `/api/v1/web-server-workflow` endpoint grubu eklendi.
- Active web server profile degerine gore Nginx veya Apache akisi otomatik secilir.
- Tek noktadan `generate -> publish -> validate -> reload` sirasi kuruldu.
- Workflow registry eklendi.
- Nginx icin guvenli simulated reload destegi workflow icine baglandi.
- Apache icin real reload izin olmadan skipped guard davranisi eklendi.

## Test

- Python compile testi basarili.
- FastAPI route import testi basarili.
- TestClient ile Nginx active profile workflow run akisi dogrulandi.
