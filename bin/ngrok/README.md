Bu klasor JHoster portable bin standardinda `ngrok` bileseni icin ayrilmistir.

Beklenen kullanim:

- Portable uygulama veya runtime dosyalari bu klasor altina konur.
- JHoster real execution varsayilan olarak kapali kalir.
- Gercek calistirma icin once process real profile, sonra preflight, sonra allow_real_execution kullanilir.
